# LoL ARAM: Mayhem（大亂鬥：海克斯）互動式攻略指南（Patch 16.23）

整合 **OP.GG**、**ARAMGG**、**Riot DataDragon** 與 **Meraki 技能公式** 的互動網頁工具（繁體中文），支援啟動自動同步最新資料、英雄海克斯選牌決策、無重複定位特化出裝合成與傷害成長模擬。

## 主要功能

1. **🎯 選牌決策與英雄配裝（整併工作台）**
   * 共用 `Lv 1 / Lv 7 / Lv 11 / Lv 15` 四階段進度槽位與即時 6 神裝合成台，並支援 `⚡ 局內三選一決策`、`📚 特化詳解與全海克斯 / OP.GG 配裝`、`🧩 決策＋圖鑑同頁展開` 三種檢視切換。
   * 僅顯示該英雄本賽季可抽選海克斯；依遊戲規則於後兩輪（`Lv 11 / Lv 15`）停用「限前兩輪」海克斯，並在選定後自動自可選快捷與詳細列表移除。
   * 自動過濾互斥定位／唯一被動裝備（魔法彎刀、百分比雙穿、命脈、九頭蛇、獻祭等），同時完整保留**女神之淚系列多件疊加推薦模式**。
2. **🧮 傷害與成長模擬器（Damage & Growth Simulator）**
   * 支援 `Lv 1 ~ Lv 18` 成長曲線與目標雙防／生命設定，試算 6 裝＋海克斯下的 Q / W / E / R 預期傷害與平砍 DPS。
   * 支援指定技能型海克斯（如「寶石手鍊」、「土司和奶油／起司／果醬」、「疾速追擊」、「追求力量」等）Q/W/E/R 目標與進度滑桿，以及「命定武器」裝備與層數模擬。
3. **✨ 海克斯百科、機制特化速查與全英雄強度榜**
   * 提供往季海克斯灰底停用區隔、機制特化裝備反查與 173 位英雄強度排行。
4. **🔄 啟動自動同步最新資料**
   * 每次透過 `start_guide.bat` 或 `serve.ps1` 啟動時，自動執行 `sync_data.ps1` 同步最新 Riot DataDragon、Meraki、OP.GG 與 ARAMGG 資料並熱更新頁面。

## 使用方式

* **本機自動同步啟動（推薦，Windows）**：雙擊 `start_guide.bat` 或執行：
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\serve.ps1
  ```
  啟動後會自動開啟／更新 `http://localhost:8765/`，並於背景同步最新資料後原地熱更新。
* **線上瀏覽（GitHub Pages）**：於 GitHub Repository 設定 **Settings → Pages**，將 Source 設為 `Deploy from a branch`（`main` / `/ (root)`）即可使用。
* **本機純靜態開啟**：直接雙擊開啟 `index.html`。
