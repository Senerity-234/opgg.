# LoL ARAM: Mayhem（大亂鬥：海克斯）互動式攻略指南（Patch 16.22）

整合 **OP.GG**、**ARAMGG**、**Riot DataDragon 16.22.1** 與 **Meraki 技能公式** 的純靜態互動網頁工具（繁體中文），提供英雄海克斯階級、裝備特化連動、局內選牌決策與傷害成長模擬。

## 主要功能

1. **⚡ 局內選牌決策（Quick Pick Decision）**
   * 依英雄與當前等級（`Lv.1` / `Lv.7` / `Lv.11` / `Lv.15`）建立進度軌，自動帶入前幾輪已選海克斯並跳轉下一階段。
   * 僅列出該英雄本賽季可抽選的海克斯，支援品質篩選（稜鏡／黃金／白銀）與勝率／協同／衝突即時試算。
2. **🧮 傷害與成長模擬器（Damage & Growth Simulator）**
   * 支援 `Lv.1 ~ Lv.18` 與目標防禦參數調整，試算 6 件裝備＋海克斯下的 Q / W / E / R 技能預期傷害與平砍 DPS。
   * 支援指定技能型海克斯（如「寶石手鍊」、「土司和奶油／起司／果醬」、「疾速追擊」、「追求力量」等）的 Q/W/E/R 目標與進度微調，以及「命定武器」裝備與層數模擬。
3. **🛡️ 全英雄海克斯與特化裝備圖鑑**
   * 完整檢視 173 位英雄之核心裝備、海克斯評級／實測勝率／選取率，以及特化連動出裝與避坑提醒（往季／已移除海克斯自動灰底停用）。
4. **✨ 海克斯百科與流派速查表**
   * 依機制分類總覽本賽季可選海克斯與對應英雄排行。

## 使用方式

* **線上瀏覽（推薦）**：於 GitHub Repository 設定 **Settings → Pages**，將 Source 設為 `Deploy from a branch`（`main` / `/ (root)`）即可生成靜態網站網址。
* **本機直接開啟**：下載後直接用瀏覽器雙擊開啟 `index.html`。
* **本機 HTTP 伺服器（Windows PowerShell）**：
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\serve.ps1
  ```
  啟動後於瀏覽器開啟 `http://localhost:8765/`。
